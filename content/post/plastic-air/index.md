『Plastic Air』は、まだ測りきれない大気中のマイクロプラスチックを、正確な科学図ではなく「近似と想像の窓」として見せるウェブ体験です。作者の Giorgia Lupi（ジョルジア・ルピ）は不確かさを隠さず、この作品を推測的（speculative）だと名乗ります。狙いは量を正しく伝えることではありません。見えないものが、いま吸っている空にあると感じさせるところまでを設計しています。

作品は 2021年の Earth Day に、Google Arts & Culture との協働で公開されました。制作は Lupi と、Pentagram の Talia Cotton、Phil Cox です。UNFCCC と Google が展開した気候実験のシリーズ *Heartbeat of the Earth* の一つでもあります。以下は、Lupi と Pentagram の作品ページ、Experiments with Google の紹介、体験本体の説明文に沿い、鑑賞者が作品に出会う順に読みます。

<!--more-->

## 「見えないけれど、そこにある」から始まる

体験は [artsexperiments.withgoogle.com/plasticair](https://artsexperiments.withgoogle.com/plasticair/) で公開されています。開くと、大きく「PLASTIC / IN THE AIR」と出て、中央に一文が置かれます。

> You don’t see it, but it's there.

見えないが、そこにある。作品全体の問いは、この一文に収まっています。中央のスイッチは、体験を始めるための操作です。押すと、空を模した画面に色とりどりの粒子が漂い始めます。

![イントロ画面。「PLASTIC / IN THE AIR」の下に、開始用のスイッチが置かれている](images/intro.jpg)

Giorgia Lupi・Pentagram／Google Arts & Culture『Plastic Air』より引用

本編の左上には、see と don’t see を切り替えるスイッチがあります。公式の説明では、これは *seen/unseen dichotomy*、見えるものと見えないものの二分法です。see では抽象化された粒子が漂います。don’t see に切り替えると、粒子の代わりにストローやキャップといった日用品が空に浮かびます。

![don’t see の状態。粒子の代わりに、ストローやキャップが空を漂う](images/dont-see.jpg)

Giorgia Lupi・Pentagram／Google Arts & Culture『Plastic Air』より引用

Fuorisalone.it は、この体験がまず「問題を見たいかどうか」を問う、と要約しています。見ないことを選ぶのは、鑑賞者自身です。冒頭の一文は、その選択を先回りしています。

なぜ「見える」ところから始めないのか。Lupi は It's Nice That の取材で、事情を説明しています。気候ストライプや海のプラスチック映像と違い、大気中のマイクロプラスチックには、指させる被害の画像が乏しい。文字どおり *out of sight, out of mind*、目に入らなければ気にも留められない題材でした。だから最初の一手は、量の提示ではなく、**見えないものがあると認めさせること**に置かれています。

## 粒子に近づくと「possibly from」と出る

本編の空に漂う粒子は、四つの形に描き分けられています。細い波形は繊維（Fibre）、直角三角形はフィルム（Film）、いびつな塊は顆粒（Granule）、太い斜めの棒は破片（Fragment）です。公式の「About this website」は、操作を Inspect、Deposit、Don’t see の順で説明しています。

最初の Inspect は、クリックではなくホバーです。粒子にカーソルを近づけると、その粒子だけが止まり、拡大レンズと属性のパネルが出ます。パネルの項目は五つです。

| 項目 | 中身 |
|---|---|
| Type | Fibre / Film / Granule / Fragment |
| Composition | ナイロン、ポリウレタン、ポリスチレンなど、想定される化学組成 |
| Possibly from | セーター、断熱フォーム、買い物袋など、想定される元の製品 |
| Size | マイクロメートル（μm） |
| Distance travelled | 移動距離（km） |

![ホバーで粒子を検査する。Type、Composition、Possibly from、Size、Distance travelled が並ぶ](images/inspect.jpg)

Giorgia Lupi・Pentagram／Google Arts & Culture『Plastic Air』より引用

目を留めたいのは、出自の欄が「from」ではなく **possibly from** になっていることです。It's Nice That は、オレンジの三角形がポリスチレンで、カトラリー由来かもしれない例を報告しています。糸状の粒子はポリエステルで、セーター由来かもしれない。どちらも「かもしれない」です。

この欄は、種類ごとに用意された製品リストから割り当てられています。繊維ならセーター、漁網、ナイロンの歯ブラシ毛。顆粒ならボトル、バンパー、使い捨てカトラリー。フィルムなら買い物袋、シャワーカーテン、ストロー。破片なら CD、床材、キーボード。一つの粒子が実際にどこから来たかを、作品は知りません。知らないことを、possibly の一語で表示しています。

Lupi は、マニフェスト「Data Humanism」で、データ駆動は紛れもない真実を意味しない、と書いていました。可視化は不完全さと近似を引き受けるべきだ、とも述べています。『Plastic Air』で彼女はこの作品を Data Humanism の実践だと書いており、ホバーの一語がその原則の実装になっています。

## 雨・都市・未来で、空の論理が変わる

画面の左には、条件を変えるボタンが三組あります。天候は Not Set / Rain / Snow、場所は Not Set / Urban / Remote、時間は Now / Future です。ボタンにホバーすると、その条件が粒子に何をするかの短い説明が出ます。

| 組 | 説明文の要旨 |
|---|---|
| 天候 | Rain は雨粒が運ぶので粒子が増える。Snow は北極で小さくなり、遠くまで行き、砕ける |
| 場所 | Urban は衣類と日用品のため繊維が増える。Remote は小さくなり、遠くまで行き、砕ける |
| 時間 | Future は除去手段がなく、2050年までに 120億トン相当が蓄積する |

条件を選ぶと、左下の凡例の数字が変わり、空の粒子構成がそれに従います。初期状態では、四種の Quantity がどれも 25% です。これは世界の平均が均等だという意味ではなく、条件を選んでいないときの既定値です。Urban を選ぶと、繊維が 90%、破片が 10% になり、フィルムと顆粒は 0% になります。Remote と Rain を重ねると、繊維が 66%、ほか三種が各 11.3% です。

![Urban を選んだときの凡例。Fibres 90%、Fragments 10%、Films と Granules は 0%](images/legend-urban.jpg)

Giorgia Lupi・Pentagram／Google Arts & Culture『Plastic Air』より引用

これらの比率は、一つの統合データから来たものではありません。作品の説明は、天候や場所ごとの挙動を、別々の地点研究から組んだと示しています。雪はアルプスから北極の積雪研究（Bergmann et al., 2019）。遠隔地はピレネー（Allen et al., 2019）と米国の保護地域（Brahney et al., 2020）。都市はパリ（Dris et al., 2015）です。

Google 側の依頼は、プラスチック汚染の危険を視覚化することでした。制約は二つありました。対象が肉眼で見えないこと。そして大気中マイクロプラスチックの研究は当時まだ始まったばかりで、決定的なデータセットがなかったことです。Experiments with Google は、University of Strathclyde と Utah State University の科学者が、科学的な検証にあたったと明記しています。

つまり空の比率は、空全体の実測ではなく、**地点研究の論理を束ねた近似モデル**です。Now / Future も確定した予報ではなく、いまの軌道を延ばしたシナリオです。体験自身が、最大のリスクは「分かっていないこと」だと書いています。

左の Clear も、空を消しません。押すと「本当にそれでうまくいくと思ったのか」という説明が出ます。プラスチックは耐久性のために作られていて、一度そこにあると消えない、と続きます。

## 「Yes! Well, sort of.」と答える

画面右端の Find out More を開くと、仕組みの説明と、参照した論文が並びます。粒子の描き方の凡例（Fig. 2）もここにあります。形は顕微鏡で見た分類に対応し、色は虹の全色に黒・白・透明を足したパレットです。サイズは 1μm（赤血球ほど）から 1,000μm（1mm）までの連続量で描かれます。

![Fig. 2。粒子の種類ごとの形、色のパレット、サイズの範囲を示す公式の凡例](images/legend-official.png)

Giorgia Lupi・Pentagram／Google Arts & Culture『Plastic Air』より引用

色は種類を見分けるコードではありません。実際の粒子がさまざまな色で見つかる、という事実の写しです。Lupi は、プラスチックそのもののように明るく光沢のある色を選んだと書いています。

この可視化は本物に近いのか。Find out More は、その問いに自分で答えています。

> Yes! Well, sort of.

形は顕微鏡分類に基づくが、可視化は抽象である、という答えです。正確だと言い切らず、まったくの創作だとも言わない。この短い答えが、作品の立ち位置をそのまま示しています。

Lupi 自身は、この体験を次のように呼んでいます。

> a speculative “window” onto a data-driven approximation

データに基づく近似を覗く、推測的な「窓」という意味です。可視化の方法論そのものが、まだ限られた推測的な情報を扱う作業だった、とも書いています。スペキュラティブ・デザインは、条件を立てて、いま見えていない現実や将来を議論できるものにします。データ可視化とスペキュラティブ・デザインが『Plastic Air』で交わるのは、この自己規定においてです。推測的であることは、科学を手放したことではありません。データの欠けを、可視化の前提として引き受けたということです。

## 第三者はこの作品をどう見たか

公開直後の評は、デザインメディアが中心でした。論点の違う三つを挙げます。

- **It's Nice That**（2021-04-22）は、*beautiful yet alarming*（美しいが、警告的）と見出しを付けました。取材では、研究がまだ始まったばかりであること、見えないものを見せるのが抽象的な難題であることを、Lupi 自身の言葉で伝えています。不確かさを、作者が自覚していたことの記録です。
- **Fast Company** は、ラテやテイクアウトが、自分の吸う空気につながるという因果を見出しにしました。典型的な曇った汚染の描写から離れ、滞在したくなる美しさを狙ったと書いています。Cox は研究者と「どんなサイトが認知を上げるか」を詰め、Cotton は色をマイクロプラスチック自体の見た目から取った、と役割の分担も記しています。
- **PRINT Magazine** は、Data Humanism を「事実と数字を人間化して問題を枠づける」と要約しました。*deeply captivating and approachable*（深く惹きつけ、近づきやすい）と評しつつ、舞う粒子を「shitty pollution party」と皮肉っています。美しさが、プラスチックの誘惑そのものを再現してしまうという両義性の指摘です。

三つの評は、精度を検証していません。問われているのは、見えない汚染を、滞在できる体験として成り立たせたかどうかです。It's Nice That は作者の自覚を、Fast Company は日常との因果を、PRINT は美しさの危うさを見ています。

## 使い道

『Plastic Air』から可視化の仕事に持ち帰れることは、データが足りないときの見せ方です。

一つ目は、不確かさを画面の言葉にすることです。possibly from の一語、Yes! Well, sort of. の一文で、作品は推定であることを隠していません。データの欠けを脚注に追いやらず、操作のたびに目に入る場所へ置いています。

二つ目は、統合データがないとき、出典の違う地点研究を「条件」として並べることです。雨・都市・遠隔地のボタンは、それぞれ別の研究の論理を切り替えています。一つの正しい地図を装うより、どの研究のどの論理かを選ばせるほうが、読み手は近似の範囲を測れます。

三つ目は、目標を「量を正しく読ませる」ではなく「あると感じさせる」に置く判断です。もちろん、正確さが求められる仕事では使えない判断です。それでも、研究が萌芽期で、被害の画像もない題材では、最初の一歩は存在を認めさせることでした。

Lupi は、近似であることを名乗ったうえで、空にあるものを感じさせるところまでを作りました。可視化の誠実さは、正確さだけで決まりません。どこまでが分かっていないかを、見せ方の一部にすることでも保てます。
