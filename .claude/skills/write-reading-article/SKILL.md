# 読み物記事を書く

## 仕上がりの目安

- 本文（「参考・出典」の節を除く）は **4,000〜7,000字**。h2 は **5〜7個**。
- 記事全体で問いは一つ、答えも一つ。タイトルが問いか主張になり、description と冒頭段落がその答えになる。
- 想定する読者は、可視化の仕事をしていて、題材の作品・論文・書籍を初めて知る人。

## 手順

1. **一文の答えを決める。** 「読み終えた人が一文で言えること」を書き、ユーザーに確認してから進める。
2. **出典を集める。** 一次情報（作者本人の文章、論文、公式ページ、書籍）を先に読み、URL・ページ番号・引用箇所を控える。第三者評価は、論点がそれぞれ違うものを 2〜3件選ぶ。
3. **アウトラインを作る。** h2 は場面か問いの形で書き、時系列か、読者が作品を見る順に並べる。
   - 場面・事例：3〜4節
   - 第三者の評価：1節（例：「第三者はこの本をどう見たか」）
   - 使い道：1節（可視化の仕事に持ち帰れることを書く）
   - 参考・出典
4. **本文を書く。** 文体は下の「文体」に従う。手本は `references/exemplars.md`。
5. **分量を測る。** `bash .claude/skills/write-reading-article/scripts/check.sh content/post/<slug>/index.md` を実行し、目安に収める。
6. **表示を確かめる。** `draft = true` のまま保存し、`hugo server -D` で記事ページを開いて、画像・目次・出典リンクを確認する。

## 文体

- です・ます調。1文は60字前後まで。1段落に主張は一つ。
- 日付・人名・数字・引用といった、具体的な事実の文で論を進める。
- 比喩は記事全体で2つまで。太字は h2 ごとに1か所まで。
- 一つの記事は一つの視点で読む。別の視点でも読みたいときは、別記事か特集（`series`）にする。
- 人名・作品名は、初出で原綴りとカタカナを併記し、以降はどちらか一方で通す。
- 英語の引用は原文をブロック引用で置き、直後に日本語で要旨を書く。
- 本文に書く事実は、出典で確認できたものだけにする。
- 作者・作品側の言葉（誰が、どこに書いたか）と、筆者の読みを、文として分ける。筆者の読みは「〜と読めます」のように、読みだと分かる形で書く。

## サイトの決まり

README の「新規記事の書き方（LLMO）」に従う。

- front matter は `references/frontmatter.md` の雛形を使う。`author` は「矢崎裕一」。
- `description` に結論を1〜2文で書く。
- 冒頭（`<!--more-->` の前）は2段落。1段落目で答えを出し、その段落だけで引用できるようにする。2段落目で出典と文脈を示す。
- 定義・比較・出典は表かリストにする。
- 画像は記事フォルダの `images/` に置き、alt に図の内容を一文で書く。画像の直下に「著者／書名より引用」のクレジット行を置く。
- 画像がない記事では `image` を書かない。タイトルからサムネイルが自動生成される。
- 「参考・出典」は **一次情報** と **第三者評価** に分け、各項目に URL か DOI を付ける。
- 英語版（`index.en.md`）は、実際に翻訳するときだけ作る。
