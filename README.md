## このサイトの内容
Hugo を利用した Visualizing.jp の2024年〜版リポジトリ。

## ローカルサーバでの確認方法

```
hugo server
```

## デプロイ方法
- ファイルを修正する
- `hugo` コマンドを実行する
- public フォルダ以下にファイルが出力される
- public フォルダ以下を Github へプッシュする
- Vercel に自動で反映させる

## 新規記事の書き方（LLMO）

既存記事の本文は改稿しない。これから書く記事だけ、次を守る。

1. `description` に結論を1〜2文で書く。空にしない。
2. 冒頭40〜120語で答えを先に出す。段落は単体で引用できること。
3. 定義・比較・出典は表かリストにする。
4. 日本語記事の `author` は「矢崎裕一」。
5. 画像には意味のある alt を書く（`![](...)` にしない）。
6. 英語版（`index.en.md`）は実翻訳のみ出す。定型の要約スタブは出さない。日本語原文が詳しいなら、薄い英語は置かない。
